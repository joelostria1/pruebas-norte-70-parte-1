Pruebas Grupo Norte 70

El codigo esta escrito en Java que fue el lenguaje que tenia a la mano y donde vienen los primeros 4 ejercicios 

Para ejecutarlo solo hay que situarse en una terminal en la carpeta src del proyecto y ejecutar 

java Main.java

O abrirlo en un editor como IntelliJ y ejecutar el programa de manera normal

Tambien se encuentra un archivo SQL que pertenece al ejercicio 5, esta con estructura para MySQL que es el primer motor de Base de datos que tenia a la mano
